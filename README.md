#Chapter 1 Overview

1- What is the cloud?
Its a group of powerful physical servers hosted in remote datacenters that can be accessed through the Internet globally.
Its an alternative way of powering business applications without the heavy capital investment needed for the physical hardware.
Example : If a company wants to back up their data instead of using on prem tape disks it could  autommtically sync backups  to the cloud. This will mitigate the risk of data being lost  if something happens to the main office like a fire 


1-What is Public Cloud?

A Public Cloud can be accessed from anywhere, where it follows a multi tenant structure meaning a shared pool resources, usally provisioned by third party vendors (e.g Oman Data Park/AWS)


| + Pros |  - Cons |
| :--- | :--- |
| **No Capital Expense:** Pay only for what you use . | **Less Security:** Resources are shared |
| **High Scalability:** Supports a wide range of plugins. | **Steep Learning Curve:** Requires terminal knowledge. |
| **Active Community:** Easy to find tutorials and support. | **Poor Documentation:** Some advanced features lack guides. |
